# Sponge holder (kitchen faucet clip)

Provisional 3D-printable hook that clips around a kitchen faucet shaft and
cradles a sponge over the sink edge. Generated from the dimensions sketched
on the reference photo (50, 57, 55, 37, 80 mm). **Not yet measured against a
real faucet** — see the parameters section before printing.

## Files

- `sponge_holder.scad` — parametric OpenSCAD source (preferred for tweaking).
- `generate_stl.py`    — Python generator using `numpy-stl` that produces
                         the STL without needing OpenSCAD.
- `sponge_holder.stl`  — current binary STL (regenerated by the script).

## Generate the STL

With OpenSCAD:

```
openscad -o sponge_holder.stl sponge_holder.scad
```

Without OpenSCAD (uses numpy-stl):

```
pip install numpy-stl
python3 generate_stl.py
```

## Parameters

Edit them at the top of either source file.

| Parameter         | Default | Meaning                                              |
| ----------------- | ------- | ---------------------------------------------------- |
| `FAUCET_D`        | 32 mm   | diameter of the chrome shaft the clip snaps onto     |
| `STRAP_T`         | 4 mm    | wall thickness                                       |
| `STRAP_W`         | 28 mm   | strap width (depth into the page)                    |
| `HOOK_WRAP_DEG`   | 220°    | how far the hook wraps around (>180 = snap-on)       |
| `DESCENT_H`       | 30 mm   | vertical drop from end of hook to cradle arm         |
| `ARM_L`           | 50 mm   | horizontal arm from descent to cradle back wall      |
| `CRADLE_BACK_H`   | 80 mm   | cradle back wall (vertical)                          |
| `CRADLE_BOTTOM_L` | 55 mm   | cradle floor (horizontal)                            |
| `CRADLE_FRONT_H`  | 37 mm   | front lip that holds the sponge in                   |

## Print recommendations

- Material: **PETG** or **TPU 95A**. PLA works but is brittle and can snap at
  the hook over time.
- Orientation: print **flat on the side** (so the strap width `STRAP_W` is
  vertical). Layer lines run perpendicular to the bending load on the hook.
- Walls/infill: 4 perimeters, 30–40 % infill (gyroid). With this profile the
  part is essentially solid anyway.
- Layer height: 0.20 mm.
- Supports: **none needed** if printed flat on the side.

## Known caveats / TODO

- Hook diameter and `DESCENT_H` are estimates — measure the faucet shaft and
  adjust `FAUCET_D` and `DESCENT_H` to match.
- Sharp inside corners on the cradle: fine for printing, but you may want to
  add fillets if the sponge frays. (Not added yet because the offset/miter
  approach in `generate_stl.py` produces backward kinks at filleted corners.)
- Confirm sponge dimensions and adjust `CRADLE_BOTTOM_L` / `CRADLE_BACK_H`.
