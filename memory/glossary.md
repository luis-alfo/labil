# Glosario

Términos que usamos Luis y Claude.

## Impresión 3D
| Término | Significado |
|---------|-------------|
| A1 | Impresora Bambu Lab A1 de Luis (no la mini) |
| AMS lite | Cargador multicolor de la A1 |
| 3MF / proyecto Bambu | Archivo de Bambu Studio con piezas, filamentos y ajustes |
| incrustación / inlay | Color a ras en las primeras capas de la cara de la cama |
| purga | Filamento que se tira al cambiar de color |
| Arachne | Generador de paredes de ancho variable (mejor para trazos finos) |
| bisel | Corte a 45° de una arista; en el agujero deja inclinarse la anilla |
| ojal | Agujero alargado para la anilla |

## ST26
| Término | Significado |
|---------|-------------|
| ST26 | Marca/proyecto de Luis (ver `projects/st26.md`) |
| llavero botella | Llavero ST26 con forma de botella bordelesa |
| bordelesa / borgoña | Tipos de botella: hombro alto y redondo / hombro largo y caído |
| cápsula | Capuchón del cuello de la botella (en el llavero, relieve negro) |
| tapón | Parte superior del cuello donde va la argolla |
| rombo de la S | Remate superior de la S del logo; hay que conservarlo al engordar trazos |
